KhataOS/Download

Download KhataOS.

Free for Windows, macOS, Linux and Android. Pick your system below and follow three or four short steps.

Latest Version Release notes

KhataOS is in alpha. Try it with a test company first, and keep your current software for your real books for now.

The first release isn't published yet. Until it is, the buttons below lead to a GitHub page that says Not Found. You can build KhataOS from source today, or watch the repository to hear when it's out.

01/Choose your systemYour device is first

  • Windows Your device

    Windows 10 or 11, 64 bit

    Download for Windows Installer, .exe
    Install steps
    1. Open KhataOS-Windows-Setup.exe when it has downloaded.
    2. Edge may say the file isn't commonly downloaded. Click the … button next to it, then Keep. If it asks again, click Show more, then Keep anyway.
    3. Windows shows Windows protected your PC. Click More info, then Run anyway. This appears because the installer isn't signed yet.
    4. Follow the installer. KhataOS appears in the Start menu.

    KhataOS needs Microsoft WebView2. Windows 10 and 11 usually have it, and the installer downloads it if yours doesn't.

    Other formats 1
    • MSI installer, for IT teams

  • macOS Your device

    One file for Apple silicon and Intel Macs

    Download for Mac Disk image, .dmg
    Install steps
    1. Open KhataOS-macOS.dmg and drag KhataOS onto the Applications folder.
    2. Open KhataOS from Applications. The first time, macOS says it can't check KhataOS for malicious software, because Apple hasn't checked it yet. Click Done.
    3. Open System Settings, then Privacy & Security. Scroll down, and next to the note about KhataOS click Open Anyway.
    4. Confirm, and enter your Mac password if asked.

    You only do this once. On macOS 14 Sonoma and older there's a shorter way: in Applications, Control-click KhataOS, choose Open, then click Open.

    Other formats

    The disk image is universal, so there's nothing else to choose. Older versions are on the releases page.

  • Linux Your device

    64 bit. The AppImage runs on most distributions.

    Download for Linux AppImage, nothing to install
    Install steps

    AppImage

    Allow the file to run as a program, in your file manager's Properties or with these commands, then open it.

    chmod +x KhataOS-Linux.AppImage
./KhataOS-Linux.AppImage

    If it mentions FUSE, install it: sudo apt install libfuse2 on Ubuntu 22.04, or sudo apt install libfuse2t64 on Ubuntu 24.04 and newer.

    Ubuntu, Debian or Mint

    sudo apt install ./KhataOS-Linux.deb

    Fedora or openSUSE

    sudo dnf install ./KhataOS-Linux.rpm

    On openSUSE, use sudo zypper install with the same file. KhataOS then appears in your applications menu.

    Other formats 2
    • .deb package, for Ubuntu, Debian and Mint
    • .rpm package, for Fedora and openSUSE

  • Android Your device

    Phones and tablets with Android 7 or later: Xiaomi, Redmi, POCO, Samsung, Vivo, Oppo, Realme and others

    Which one do I need? Most phones need the main download. If your phone says the app isn't compatible, try the one for older 32 bit phones, under Other formats.

    Download for Android App file, .apk, for most phones
    Install steps

    KhataOS isn't in the Play Store yet, so your phone asks you to confirm a few times. That's normal for apps from outside the store. These steps use Chrome; other browsers ask the same things.

    1. Tap Download for Android. If Chrome warns that this type of file can harm your device, tap Download anyway.
    2. When it finishes, tap Open. You can also find the file later in Downloads or the Files app.
    3. The phone says it isn't allowed to install unknown apps from this source. Tap Settings, turn on Allow from this source, then go back.
    4. Tap Install.
    5. If Google Play Protect says Unsafe app blocked, or that it doesn't recognise the developer, tap More details, then Install anyway.
    6. Tap Open. KhataOS is now in your app list.

    Xiaomi, Redmi and POCO phones

    On HyperOS and MIUI, the phone's security app scans KhataOS first and may say it is unknown or not verified. It may ask you to tick a box to say you understand the risk, and wait a few seconds, before you can continue. The exact words differ between phones.

    Once KhataOS is installed, you can turn Allow from this source off again. KhataOS keeps working.

    Uninstalling deletes your books. Back up each company first with Alt+Y → Backup, and save the file outside the app (how to back up). To update, install the new version over the old one: that keeps your books.

    Other formats 3
    • Older 32 bit phones
    • Emulators and Chromebooks (x86_64)
    • Any phone, in one larger file

    The main download suits almost every phone made since 2017. A file ending in -unsigned.apk is for people who sign apps themselves: Android can't install it as it is. Every file is on the releases page.

  • iPhone and iPad Coming later Your device

    Apple only allows apps from the App Store, or apps signed with a paid developer account, and KhataOS isn't in the App Store yet. For now, use it on a computer or an Android phone.

    Build it from source Needs a Mac with Xcode

02/Good to know

Want it on your phone?

Point your phone's camera at this code. It opens this page there, with the right download at the top.

A link says Not Found?

That file isn't in the newest release yet. Every file, and every older version, is on the releases page. Developers can also build from source.

03/Is it safe?Why your system warns you

Open code, built in public.

Windows, macOS and Android warn about any app that isn't signed with a paid certificate or isn't from their store. KhataOS isn't signed yet. The warning means your system doesn't know who made the app. It doesn't mean it found a problem.

It's open source

All of the code is public on GitHub. Anyone can read it and check what it does.

It's built in public

GitHub's servers build every installer from that public code, and anyone can see the build logs.

Your books stay with you

KhataOS works offline. Nothing is sent anywhere unless you choose to share your books or send a report.

You can check your file

Each release lists a SHA-256 fingerprint for every file in SHA256SUMS.txt. The install guide shows how to compare.

Download only from here

Get KhataOS from this page or the KhataOS releases page, and nowhere else.
